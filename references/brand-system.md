# 品牌系统

本规范以 Big Walk 当前品牌套装为视觉原稿，以官网和客服工作台为媒介适配参考。轮廓毛边的实际实现、参数与源稿差异见 texture-and-shape.md。色值、字体与 SVG 形状是现有来源；下文留白、比例和小尺寸建议是用于新产物的一致性默认值，可随媒介调整。

## 色彩

| Token | 色值 | 用途 |
|---|---|---|
| cream | #F3ECDF | 品牌主底、页面背景 |
| paper | #FAF6EE | 内容面板、阅读区域 |
| ink | #1C1A17 | 标题、正文、边框、反色区块 |
| ink-2 | #3B352C | 次级正文 |
| muted | #5A544B | 辅助说明 |
| line | #D9CFBE | 低强调分隔线 |
| blue | #4C74B9 | 主品牌色、图形、大块面 |
| blue-deep | #3A5E9E | 需要更强对比的蓝底按钮、文字 |
| yellow | #F1C543 | 主 CTA、强调标签、圆形 |
| red | #C23B1E | 标题重点、蛇舌、少量强调 |
| pink | #EFA3B3 | 角色与点缀 |
| green | #3E9A5E | 角色与点缀 |
| plum | #8A2350 | 角色与点缀 |

默认让中性色占主要面积，每个视图有一个主强调色，另用一至两个局部点缀。不要把所有品牌色均分成彩虹卡片。深色区块用 ink，奶油色文字，彩色角色点缀。

普通小字优先 ink / ink-2 / muted 配 cream / paper；黄色用墨黑字。品牌蓝上的小白字需要核对对比度，必要时改 blue-deep。浅描边只用于非关键分隔，表单边界与焦点需足够清楚。

## 字体

| 用途 | 首选 | 回退与使用 |
|---|---|---|
| 中文大标题 | Noto Serif SC，900 | Songti SC、STSong、Source Han Serif SC、serif |
| 英文短标签/口号 | Alfa Slab One | Rockwell、Georgia、serif；避免长段文字 |
| 正文/产品 UI | 系统中文无衬线 | PingFang SC、Hiragino Sans GB、Microsoft YaHei、Noto Sans SC、sans-serif |

官网 `CM Display` / `CM Latin` 是字体别名，不是可直接下载的字体名称。本包 assets/fonts/ 附带 Google Fonts 官方原始 Noto Serif SC 可变字体与 Alfa Slab One，使用 fonts.css 加载；对应 OFL 许可一并保留。中文文件包含完整上游字形，不能用旧网站的有限字符子集替代新的正文。下载体积较大的字体在正式网站中可按真实字符集优化，但须保留授权信息并检查新增字符。

默认网页字号：英雄标题 clamp(44px, 6vw, 84px)，段标题32–48px，正文17px/1.75，导语19px；小英文标签12–16px、字距0.12–0.18em。实际官网和各海报字号随画布变化，不要求所有媒介用同一字号。

## Logo：直接使用，不重画

文件命名：`assets/logos/{mark|horizontal|vertical}-{color|black|white}.svg`。这9个原始导出含画布留白，适合品牌物料。网页导航和紧凑界面优先使用已有官网紧边界版本 `horizontal-web-color.svg` / `horizontal-web-white.svg` / `mark-web-color.svg`，不要把画布宽度误当图形实际宽度。

- mark：云形曼巴图形；用于头像、图标或已有文字品牌旁。
- horizontal：横版组合；官网导航、文档页眉默认。
- vertical：竖版组合；方形头像、封面与竖幅构图。
- color：浅色背景默认；black：单色墨黑；white：蓝底或墨黑底反白。
- 已保留原始矢量毛边与轮廓文字，不需要再对 Logo 施加粗糙滤镜。保持 viewBox 与长宽比；不要改变头眼、舌头、字标间距，不加渐变或柔光。
- 默认四周留出至少标志高度的1/4作为净空。横版在网页可从118×44px左右开始检查，过小不能清楚阅读时用 mark，避免强压缩字标。
- 单独图形若是装饰用空 alt；承载品牌/链接含义时给出“云曼巴 Cloud Mamba”的可访问名称。

## 曼巴小队

资源是官网现有矢量形状的独立导出，内嵌所需滤镜，可直接用 `<img>`：

| 文件 | 姿态 | 身体/头部 |
|---|---|---|
| stand-red-green.svg | 站立 | 红/绿 |
| stand-pink-blue.svg | 站立 | 粉/蓝 |
| coil-yellow-plum.svg | 盘绕 | 黄/梅红 |
| coil-blue-plum.svg | 盘绕 | 蓝/梅红 |
| swim-pink-blue.svg | 游动 | 粉/蓝 |
| swim-yellow-red.svg | 游动 | 黄/红 |

保留粗圆角身体、单只白眼黑瞳、几何蛇头与红色分叉舌头。默认复用原资产，不生成写实蛇、毒牙或恐怖表情。需要新姿态时先明确这是品牌延展，沿用现有几何结构。角色用于解释协同、模块和陪伴，避免挡住内容。图标级尺寸使用简洁 mark，不强行缩小整只角色。

## 图形语法

- 平涂色块：蓝色大圆可裁切出画面；搭配黄/红的小圆，构成不对称平衡。
- 粗线：品牌横线4–7px，墨黑；比例随画布缩放。
- 标签：黄色矩形底，底层 rough、前景短文字 roughtext，分层且平直。当前套装没有旋转；不把正文都变成贴纸。
- 软件窗口：原稿是墨黑实体底壳（圆角18），奶油内层向内留14px（圆角8）；红/黄/蓝圆点。左黄块放云蛇，右墨黑块放蓝/奶油/红色条与黄色圆箭头。外壳有毛边、无投影；真实产品界面不用照搬此插画结构。
- 箭头：粗线右上箭头，可置于黄色圆形；装饰箭头与真正操作按钮需有明确区别。
- 阴影：当前品牌套装无阴影；产品工作台局部可沿用2–3px实色硬阴影，不把它扩展成整套营销风格。
- 毛边：图形 rough 为0.035 / 2 octaves / seed7 / scale5，文字 roughtext 为0.09 / 2 / seed3 / scale3.5；另有轻量 roughlite。实际采用方式和参数边界见 texture-and-shape.md；不能只写“手作”而输出完全光滑的文字与色块。
- 动效：轻微位移、形状缓动即可；操作反馈约150–200ms。装饰动效可关闭，减少动效时禁用循环与大位移。

## 不采用

大面积荧光渐变、深蓝科技光效、玻璃质感卡片、泛用大脑/芯片图标、写实医疗图库主视觉、全页面药丸圆角、装饰盖住数据。现有官网导航的轻度背景模糊只是局部实现，不等于整套品牌采用玻璃风格。
