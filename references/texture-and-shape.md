# 毛边、造型与原稿依据

## 原稿优先级与已核对的差异

以 `设计稿/01-Big Walk 套装（当前方向）` 的标志、名片、演示文稿封面、小红书封面与招聘海报为主；`02-Big Walk 风格探索` 的曼巴小队、六种情绪等用来理解造型机制。镂空、舌头、徽标对比是探索，不自动成为新的正式标志。

这两个文件夹已逐文件核对：当前套装的大字、黄条文字、短英文口号都有毛边；圆形、色条、粗线、软件窗口黑底壳也有毛边。当前套装中没有 `rotate()`、`box-shadow` 或 `text-shadow`。它的手作感来自边缘，不靠歪斜、阴影或纸张噪点。官网和工作台是在该语言上的适配，不应反过来覆盖原稿细节。

以下参数来自原 HTML；它们是设计坐标中的数值，不是所有尺寸都必须维持相同的屏幕像素强度。

## 四个滤镜定义，三档轮廓处理

| 原稿 ID / 包内 ID | frequency | octaves | seed | displacement scale | 实际用途 |
|---|---:|---:|---:|---:|---|
| rough / cm-rough | 0.035 | 2 | 7 | 5 | 圆形、色块、粗横线、窗口黑底壳、曼巴身体等 |
| roughtext / cm-roughtext | 0.09 | 2 | 3 | 3.5 | 中文标题、英文 slab、品牌短标签 |
| roughlite / cm-roughlite | 0.03 | 1 | 7 | 2 | 探索稿部分情绪版本的轻量轮廓；套装有定义，但未使用 |
| lockfx / cm-lockfx | 0.09 | 2 | 3 | 3.5 | 原始组合标志字标的更大纵向滤镜边界；正式导出已转路径 |

全部使用 `feTurbulence type="fractalNoise"` → `feDisplacementMap in="SourceGraphic" in2="n" xChannelSelector="R" yChannelSelector="G"`。这会改变可见轮廓，不会在色块内部铺满噪点。保持实心平涂。

滤镜扩边：rough / roughlite 为 x/y −10%、width/height 120%；roughtext 为 x −5%、y −10%、width110%、height120%；lockfx 为 x −5%、y −15%、width110%、height130%。避免笔画、箭头或舌头被滤镜边界切掉。

注意：官网曾将文字 scale 降为3；Big Walk 套装原值为3.5。本包品牌原稿档使用3.5，不能把网站适配值描述为唯一原始标准。

## 正确地分层

**黄色标签**：定位容器不加滤镜；绝对定位的黄色底层应用 cm-rough；前景短文字应用 cm-roughtext。字体粗细、文字毛边和底色毛边各自独立。不要在同一个父层再叠加第二遍滤镜。

**软件窗口插画**：原稿440×320（PPT）或640×430（招聘）画布。底层是圆角18的墨黑实体壳，独立应用 cm-rough；内层 inset14，奶油底、圆角8，padding16px 18px 18px。顶部三圆点为红/黄/蓝，直径24、间隔10，同样有图形毛边。主体左右两栏、间隔10；左黄块放云蛇，右墨黑块放蓝/奶油/红/奶油条，右下是黄色圆按钮与右上箭头。

外壳原稿是14px厚的实体留边，不是3px细描边加7px投影。只扭曲外壳或明确的图形子层，不把整个窗口连同正文/数据一起滤镜化。实际产品工作台不是这张插画，仍采用细边界与清晰网格。

**大圆与粗线**：圆的形状仍是明确的圆，边缘有缓慢的微起伏；横线仍有视觉上的水平走向，但边缘略不齐。先创建几何形状，再加轮廓扰动，不手工画成随意的云团或大幅波浪。

**已有资产**：本包 logo 的边缘已转路径；mascot SVG 内部已含滤镜。再次套 `.cm-rough-shape` 会双重扰动。缩放原 SVG，保留内部留白和舌头。

## 字体与光学细节

- 中文 Noto Serif SC 900：粗笔画、宋体的粗细对比与衬线转角保留下来，再加细密毛边。不能用普通黑体加粗替代；也不能靠增加噪点挽救错误字体。
- 英文 Alfa Slab One：宽厚的 slab 轮廓，品牌口号短而紧凑。原稿短标签常用 letter-spacing3px、line-height1.35；招聘巨型标题142px、字距0、行高1.02。
- 原稿中文字：PPT104px/1.12；小红书150px/1.1；招聘中文86px；黄色标签30/36/38px。作为画布比例参考，而非网页强制字号。
- PPT 原稿横线和 logo 左边96，标题左边90；小红书对应72与66；招聘对应86与80。标题向左多出6px是光学对齐，不把所有盒子机械地设为同一 left。
- 正文、联系方式、数据、图例与真实 UI 控件保持无衬线和清晰轮廓。营销短标签与操作标签不同；不能为了可读性把所有品牌标签的毛边一概删掉。

## 曼巴造型细节

已有独立 SVG 为首选。原稿常规角色使用18单位宽的粗“面条”身体、圆端点和圆连接；头部以半径19的圆与几何尖口拼合，眼白半径10.5、瞳孔5.5。舌头是4单位红色分叉线，圆端点，较身体显著更细。云形标志的身体22、眼白11、瞳孔5.7，有其独立比例，不能直接替换成普通角色头。

白色眼睛是干净且醒目的形状，瞳孔向前偏移，建立视线；头身撞色。平涂、无高光和立体阴影。姿态和重心可以活泼，整体版式仍平直。以表情探索理解变化方式，但正式资产不擅自改眼睛比例或把角色贴到图标级小尺寸。

## 网页接入

1. 复制 `fonts.css`、`fonts/`、`tokens.css`、`rough.css` 和所需图形。
2. 把 `motifs/rough-filters.svg` 整段 SVG 内联在 body 里一次。定义可以0×0，不能 `display:none`。`<img src="rough-filters.svg">` 不会注册当前文档的 filter ID。
3. 给品牌标题/口号添加 `cm-rough-type`；形状添加 `cm-rough-shape`；需要轻量处理时显式选择 `cm-rough-lite`。参考页已接入这些类。
4. `cm-paper-tag` 的毛边底色由伪元素产生，内部 span 单独设 `cm-rough-type`。`cm-window` 的底壳同理，不向内容继承滤镜。
5. 每个页面只包含一套同名 ID。组件框架中把定义放在应用根部；嵌套 SVG 或多实例时做 ID 命名空间管理。

## 尺寸与导出

原稿有物理画布比例：先在原设计尺寸构图、应用滤镜，再等比整体缩放。网页使用响应式字号时，微小文字应减弱或去掉滤镜，不能只缩字体却保留巨型标题的扰动强度。`rough.css` 的默认小屏规则在品牌短标签上减为轻量，并保持正文无滤镜；若做固定画布导出，使用画布模式保留原始参数。

对比 `assets/texture-study.html`：同字、同字体、同尺寸下对照平滑/文字毛边/图形毛边/轻量毛边。最终尺寸1:1可见不规则边缘，放大200%时边缘仍实、不发虚。小字号看不清时调弱，不能通过模糊代替。

SVG滤镜在部分 PPT/PDF/设计软件中可能不被保留。品牌标志使用已有转路径 SVG；动态文字或新图形应先在支持滤镜的渲染器里检查，必要时高分辨率栅格化该装饰层，再保持其他文字可编辑。栅格导出先2–3倍渲染后缩小，避免把低分辨率锯齿误认为毛边。交付时说明纹理层是否栅格化。

## 验收清单

- 正确字体已经加载，中文/英文都不是回退字体。
- 大标题笔画、黄条、粗线、大圆、窗口外壳实际出现对应档位的毛边。
- 毛边内部仍是平涂，无全页颗粒、模糊或故意像素化。
- 没有为了“手作”默认旋转页面元素，或以投影冒充厚底壳。
- 文字/底色分层；已有 logo/角色没有重复滤镜；舌头和衬线没有被裁切。
- 在最终输出尺寸检查过，原稿风格和界面可用性均保留。
